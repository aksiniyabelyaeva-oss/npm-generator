# НПМ-генератор для АГР
Автоматическая сборка низкополигональных моделей зданий по исходным данным заказчика.


## Журнал экспериментов: поиск окон (project_01)

Эталон: `windows_checked.json`, 70 проёмов, проверено специалистом.

| # | Изменение | Precision | Recall | F1 | Решение |
|---|---|---|---|---|---|
| 1 | Створки по линиям рам + группировка | 82% | 87% | 85% | база |
| 2 | + отсев вытянутых створок (фальцы) + фрамуги | 83% | 90% | 86% | оставить |
| 3 | + окно из одной створки должно иметь что-то внутри | — | — | — | отказ: polygonize даёт мозаику, ломает все одиночные окна |
| 4 | + окно из одной створки должно быть в раме (10–300 мм) | 94% | 86% | 90% | оставить |
| 5 | допуск рамы 5–500 мм | 94% | 86% | 90% | отказ: без изменений, строже лучше |

Остаток: 4 лишних (кровля на фасаде 4, блоки на фасаде 5), 10 пропущенных (слуховые окна, одиночные проёмы без рамы).
