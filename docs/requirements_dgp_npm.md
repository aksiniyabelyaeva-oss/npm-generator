## Открытые вопросы
- Расхождение фасадов альбома между собой (до 0,85 м) при требовании соответствия буклету.
- Точка привязки: п. 3.14 «сброшены» и п. 8.1 «углы = углам ОКС в плане» — уточнить на следующей модели.
- Модель благоустройства — после того как ОКС будет готов.
